# SQLTutor(AI)

Платформа для изучения SQL с интерактивными заданиями и AI-помощником.

## Возможности
- Единый учебный маршрут: лекции и практика внутри одного курса («Обучение» в меню)
- Видеоуроки: администратор добавляет ссылку (YouTube, Rutube или прямой .mp4/.webm), пользователи смотрят прямо на платформе
- Выполнение и проверка SQL-запросов
- AI-помощник на базе OpenRouter
- Отслеживание прогресса обучения и «Продолжить обучение» на главной
- Административная панель
- Telegram-бот: привязка аккаунта со страницы профиля (Профиль → Настройки → Telegram)

## Привязка Telegram-бота
1. Создайте бота у @BotFather, получите токен.
2. Заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` (без `@`) в `.env` API.
3. Пользователь открывает «Профиль → Настройки → Telegram», нажимает «Привязать Telegram» и следует инструкции: бот открывается по кнопке, привязка подтверждается автоматически.

## Видеоуроки
В админке («Лекции и роадмапы») вставьте ссылку на видео в блоке «Видеоурок» — блок добавится в содержимое лекции. Поддерживаются YouTube, Rutube и прямые ссылки на видеофайлы (.mp4, .webm, .ogg, .m4v, .mov); другие источники отклоняются валидацией API.

## Технологии
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: NestJS, TypeScript
- База данных: PostgreSQL, Prisma
- AI: OpenRouter

## Запуск проекта
1. Установите Node.js, pnpm и Docker.
2. Установите зависимости: `pnpm install`.
3. Настройте переменные окружения по образцу `.env.example`.
4. Запустите PostgreSQL и выполните миграции Prisma.
5. Запустите frontend и backend командами, указанными в `package.json` соответствующих приложений.
