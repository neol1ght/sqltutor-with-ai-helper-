# SQLTutor(AI)

Платформа для изучения SQL с интерактивными заданиями и AI-помощником.

## Возможности
- Обучающие курсы и SQL-задания
- Выполнение и проверка SQL-запросов
- AI-помощник на базе OpenRouter
- Отслеживание прогресса обучения
- Административная панель
- Telegram-бот и интеграция с аккаунтом

## Технологии
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: NestJS, TypeScript
- База данных: PostgreSQL, Prisma
- AI: OpenRouter

## Запуск проекта
1. Установите Node.js, pnpm и Docker.
2. Установите зависимости: `pnpm install`.
3. Настройте переменные окружения по образцу `.env.example`.
4. Запустите PostgreSQL и выполните миграции Prisma.
5. Запустите frontend и backend командами, указанными в `package.json` соответствующих приложений.
